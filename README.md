# Lab_Automation
This repo shows few examples of running test equipment over python. 
## Current stable version
Among files in static folder, select python_lab_demo in Spyder IDE. Connect RF spectrum analyzer and RF generator, click run. Script will plot two graphs. It will display equipment IDNs and first dataset in terminal. ![alt text](image.png) It will save first set of data in the /static/Data folder. ![alt text](image-1.png)
